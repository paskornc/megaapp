# สมุดลูกหนี้

เว็บแอปไฟล์เดียวสำหรับบันทึก **ลูกหนี้ / รายรับรายจ่าย / พอร์ตลงทุน** เปิดใช้ได้ทันทีโดยไม่ต้องติดตั้งหรือมีเซิร์ฟเวอร์

- ไฟล์หลัก: `index.html` (HTML + CSS + JS ทั้งหมดอยู่ในไฟล์เดียว)
- โฮสต์: GitHub Pages

## ใช้งาน

เปิด `index.html` ผ่าน GitHub Pages:

```
https://paskornc.github.io/megaapp/
```

หรือเปิดไฟล์ `index.html` ในเครื่องก็ใช้ได้ (แต่แนะนำให้เปิดผ่าน Pages เพราะ Notification API ต้องใช้ https)

## ฟีเจอร์

**ลูกหนี้** — ตารางรายเดือน, ยอดหลัก/ดอกเบี้ย/ค้างสะสม, สถานะ (จ่ายแล้ว / รอถึงกำหนด / เกินกำหนด), แจ้งเตือนครบกำหนดล่วงหน้า 1 วัน, คัดลอกข้อความทวง, แนบสลิปและรูปทรัพย์สิน, ธีม 5 แบบ

**รายรับรายจ่าย** — กระเป๋าเงิน, หมวดหมู่พร้อมไอคอน, บันทึกรายวัน, รายงานและกราฟ

**พอร์ตลงทุน** — หุ้นสหรัฐ/หุ้นไทย/คริปโต, อัปเดตราคาอัตโนมัติระหว่างเปิดหน้า, ดูกำไร/ขาดทุน

## ข้อมูลเก็บที่ไหน

แอปนี้เดิมทำงานบน runtime ของ Claude artifact (`claude.use("db" / "assets" / "downloads" / "sample" / "mcp")`)
เมื่อโฮสต์บน GitHub Pages ทุกจุดจะตกไปโหมดสำรองอัตโนมัติ คือ:

- ข้อมูลเก็บใน `localStorage` ของเบราว์เซอร์เครื่องนั้น (ไม่ซิงก์ข้ามเครื่อง, ล้าง site data แล้วหาย)
- อัปโหลดรูป/สลิป และนำเข้าพอร์ตจากภาพหน้าจอ ใช้ไม่ได้
- สำรองข้อมูล (JSON/CSV) ยังใช้ได้ แต่จะแสดงเป็นกล่องข้อความให้คัดลอกแทนการดาวน์โหลดไฟล์
- กู้คืนจากไฟล์สำรองใช้ได้ตามปกติ

**แนะนำ:** กด "สำรองข้อมูลทั้งหมด (JSON)" เป็นระยะ แล้วเก็บไฟล์/ข้อความไว้ เพราะข้อมูลผูกกับเบราว์เซอร์เครื่องเดียว
