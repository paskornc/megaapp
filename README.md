# สมุดลูกหนี้

เว็บแอพไฟล์เดียว (`index.html`) — ติดตามลูกหนี้ ดอกเบี้ย รายรับรายจ่าย โควต้าใช้จ่ายรายวัน และพอร์ตลงทุน

## วิธีโฮสต์บน GitHub Pages
1. สร้าง repository ใหม่บน GitHub (แนะนำตั้งเป็น **Private** เพราะเป็นข้อมูลการเงิน — หมายเหตุ: Pages ของ repo private ต้องใช้แพลน GitHub Pro/Team ขึ้นไป)
2. อัปโหลดไฟล์ `index.html`, `.nojekyll`, `README.md` ไว้ที่ root ของ repo
3. ไปที่ Settings → Pages → Source: **Deploy from a branch** → Branch: `main` / `(root)` → Save
4. รอ 1–2 นาที เปิดที่ `https://<ชื่อผู้ใช้>.github.io/<ชื่อ repo>/`

## ซิงก์อัตโนมัติด้วย Supabase (มือถือ ↔ คอม)

แอพเก็บข้อมูลใน `localStorage` ก่อนเสมอ (เปิดได้แม้เน็ตหลุด) และซิงก์ขึ้นฐานข้อมูล **Supabase** (Postgres ฟรี) เป็นรายแถวทุก 5 วินาที — ไม่ต้องกดปุ่ม

โปรเจกต์ฐานข้อมูลสร้างไว้แล้ว: `megaapp-debtors` (`https://qezwzbxowckwoiihoyni.supabase.co`)
— URL และ publishable key ฝังเป็นค่าเริ่มต้นในแอพแล้ว เครื่องใหม่จึงต้องกรอกแค่ **email + รหัสผ่าน**

บนเครื่องใหม่/มือถือ:
1. เปิด `https://paskornc.github.io/megaapp/`
2. แท็บ **ลูกหนี้ › รายงานสรุป › ซิงก์อัตโนมัติ** → ใส่ email + รหัสผ่าน → กด **เชื่อมต่อ** → รอ ~5 วิ ข้อมูลจะไหลลงมาเอง

ถ้าจะสร้างฐานข้อมูลใหม่เอง (หรือย้ายโปรเจกต์): สร้างโปรเจกต์ที่ supabase.com → **SQL Editor** วาง [`supabase.sql`](supabase.sql) → **Run** → **Authentication → Providers → Email** ปิด **Confirm email** → เอา Project URL + publishable/anon key มาใส่ในช่องในแอพ

หลักการ:
- ซิงก์ **รายแถว** ตาม id — ส่ง/รับเฉพาะรายการที่เปลี่ยน เบาและเร็ว
- เครื่องที่ต่ออยู่แล้วจะดึงข้อมูลเองทุก 5 วินาที และส่งของที่แก้ขึ้นทันที (ดีเลย์ ~1 วินาที)
- การลบซิงก์ด้วย (แถวจะถูกทำเครื่องหมายลบ)
- เครื่องอื่นเข้าด้วยบัญชีเดียวกันเสมอ — ข้อมูลแยกกันตามผู้ใช้ด้วย Row Level Security
- anon key เป็นคีย์สาธารณะของโปรเจกต์ (ปลอดภัยเพราะ RLS) แต่ **อย่าเอา service_role key มาใส่**
- รหัสผ่านไม่ถูกเก็บ แอพเก็บเฉพาะ session token ในเบราว์เซอร์เครื่องนั้น

## ข้อมูลอยู่ที่ไหน (สำคัญ)
- ข้อมูลเก็บใน **localStorage ของเบราว์เซอร์** เป็นหลัก (ใช้ได้แบบ offline) และซิงก์ขึ้น Supabase เมื่อเชื่อมต่อแล้ว — ถ้าไม่เชื่อมต่อ ข้อมูลจะอยู่เฉพาะเครื่องนั้น
- **ย้ายข้อมูลจากเวอร์ชัน Claude:** เปิดเวอร์ชันเดิม → แท็บรายงานสรุป → "สำรองข้อมูลทั้งหมด (JSON)" แล้วเปิดเว็บใหม่ → รายงานสรุป → "กู้คืนจากไฟล์สำรอง"
- สำรองข้อมูลเป็นระยะด้วยปุ่มเดียวกัน
- ใครเปิด URL ได้ ก็เห็นแค่หน้าแอพเปล่า (ข้อมูลอยู่ในเครื่องผู้ใช้ ไม่ได้อยู่ใน repo) แต่ไม่ควรใส่ข้อมูลจริงลงในไฟล์ใน repo

## อัปเดตราคาหุ้นสหรัฐอัตโนมัติ (ใส่คีย์ฟรี)

บน GitHub Pages ไม่มีตัวเชื่อมต่อ Alpha Vantage/CoinGecko ของ Claude แอพจึงเรียก API จากเบราว์เซอร์โดยตรง
Yahoo/Stooq ไม่ได้เปิด CORS ให้เว็บอื่นเรียก จึงต้องใช้ API ที่มีคีย์ (ฟรี ไม่ต้องผูกบัตร)

1. สมัครที่ https://finnhub.io/register → คัดลอก API key จากหน้า Dashboard
2. เปิดแอพ → แท็บ "พอร์ตลงทุน" → ช่อง **คีย์ Finnhub (ฟรี)** → วางคีย์ → กด Tab/คลิกที่อื่น
3. แอพจะดึงราคาหุ้นสหรัฐทันที และอัปเดตอัตโนมัติทุก 1 นาทีขณะเปิดหน้านี้ (ฟรี 60 คำขอ/นาที)

ทางเลือก: Twelve Data (https://twelvedata.com) ใส่ในช่องถัดไป ใช้เมื่อไม่มีคีย์ Finnhub (ฟรี 8 คำขอ/นาที, 800 เครดิต/วัน)

คีย์เก็บใน `localStorage` ของเครื่องนั้น และถูกตัดออกจากไฟล์สำรอง JSON อัตโนมัติ
